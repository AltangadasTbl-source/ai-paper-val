# Preprocessing Limitations and Missing-Asset Record

- Evidence preparation used only the four direct PDFs supplied in this package. No external literature, websites, sibling packages, or prior audit derivatives were consulted.
- No DOC, DOCX, XLS, XLSX, or CSV direct source exists in the package root, so Office conversion and Office-structure extraction were not applicable.
- DOC-002 includes embedded blank/non-substantive PDF pages 140-162 and several separator/blank pages near its SAP-update references. They were still counted, extracted, rendered, and covered as direct source units; their absence of substantive text is not an OCR failure.
- PDF native text can flatten visual tables or alter reading order. Corresponding `-layout` text and 150-dpi PNG renderings were generated for every page so later reviewers can use visually faithful table/figure evidence.
- OCR was not run because native/layout text and page renders were usable for all result-relevant units. Any later interpretation requiring text from a non-result-relevant blank page would remain unavailable because the source page itself is blank/non-substantive.
