# DOC-003 Protocol Mapping: PDF pages 65-96

## Scope and method

Assigned scope: `joi190092supp2_prod.pdf`, PDF pp. 65-96 inclusive (32 PDF pages), which contain the Manual of Operation and Procedures front matter and internal manual pp. 1-32. Direct source confirmation used `pdftotext -layout -f 65 -l 96` on the supplied PDF. The output matched `.ai_paper_validation/review_1_5_1/preprocessing/protocol_pp065_096_layout.txt` byte-for-byte. Textless/layout-poor but content-bearing PDF pp. 74, 80, 81, 83, 84, 89-91, 94, and 96 were rendered from the direct PDF and CPU-OCR inspected; tables/flowchart values below use visual confirmation where noted.

This is a protocol/manual, not a report of observed trial outcomes. Thus all mapped relationships are planned design, endpoint, eligibility, treatment, safety, follow-up, or data-collection definitions. `MPK` is a proposed matching-main-paper key for later cross-source matching, not a claim that the main paper uses an identical analysis population or wording. No legacy review artifacts were consulted.
