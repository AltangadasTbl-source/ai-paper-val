# DOC-002 support evidence extraction — shard support-001, PDF pp. 1–50

## Scope and method

Fresh-mapped `joi180004supp1_prod.pdf`, physical PDF pages 1–50 inclusive (the original CAAM protocol, version 1.3, dated 20 November 2014). Read the newly prepared PyMuPDF simple and layout text assets page by page. No OCR, prior audit derivative, web source, or source modification was used. Locations below use the supplied-PDF physical page number; the protocol's printed page number is supplied where it aids identification.

This segment is a planning/protocol document, not a results supplement. It contains outcome definitions, planned analyses, sample-size inputs, and cited background results that can be used only after matching population, analysis, and time point to a main-paper result. It contains no trial results table or participant-level data.
