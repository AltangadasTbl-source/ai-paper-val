2. Abstract secondary SCD (0.50 vs .84/1,000 days; difference -.34 [-.73,.05], RR .77 [.61,.97], P=.03) matches Table 3/narrative exactly (M26).
3. Abstract totals 144,539 discharges and 559,443 patient-days match Figure 1, Results, and Table 3 denominators (M02, M11, M17, M24).
4. Figure 1 counts, Table 1 baseline volumes, Results baseline/intervention totals, and Table 3 denominators reconcile as stated above. Excluded preimplementation BedsidePEWS-site baseline data (3,134 discharges/13,769 days) are distinct from the randomized 21-hospital analytical population and not added to the 21-hospital baseline totals.
5. All Table 2 and Table 3 interval endpoints are ordered. Direction of point estimates and intervals is coherent at printed precision. P values are not reconstructed because the source does not provide all compatible model/variance inputs; no displayed `P=0` is present.
6. No mapper-local candidate lead was identified from the direct main-paper source. This is a coverage observation only; independent numeric/statistical/cross-source checkers perform candidate discovery and adjudication remains outside mapper scope.

## Completeness statement and limitations

Mapped 37 distinct mapper-local relationships covering all direct main-paper result-relevant quantities in the abstract, methods/definitions, Figure 1, Tables 1-3 and their footnotes, Figure 2/caption, result narrative, discussion, and limitation statements. PDF pp. 10-11 are author information/references and contain no further result relationship beyond bibliographic citations. Native text order is imperfect for Table 3, so fresh layout text and PDF page rendering were used to establish row/column alignment. Model-adjusted estimates are retained as printed; crude-count arithmetic is used only for denominators/rates/percentages where its rule is explicit.
