- Normalized and bbox artifacts were produced by legacy direct Poppler pdftotext layout/bbox extraction, as recorded by native_layout_quality_report.json and scoped_native_preprocessing.py. Version of the legacy engine is not recorded; current comparison engine is version 26.01.0.
- D01/D04 older native text used PyMuPDF, as recorded by extract_native_text.py; its character corruption is documented by native_extraction_quality.json. These are PARTIAL locator aids and are superseded by canonical layout text.
- OCR text and OCR JSON use legacy RapidOCR ONNX Runtime CPU, with engine/provider metadata in the structured OCR and ocr_backend.json; model/table transcription must be confirmed in canonical layout or direct PDF. No GPU was probed or invoked in this run.
- Legacy document-output page images used PyMuPDF at 300 dpi, as recorded by render_selected_pages.py. File identified valid PNG dimensions for all images. Historical review_1_5_1 images and crop engine versions are unrecorded; their naming, text companions, and source page identities establish location only. Their exact rendering engine is not asserted.
- Structural records and evidence maps are legacy JSON source-linked metadata/transcriptions. Reuse is limited to identity, location, extraction, and reported evidence fields. Historical scientific processing status and linked candidate/checker/report fields are ignored.
- Hash command: `sha256sum -- "PACKAGE_RELATIVE_ASSET"`, one file per hash row. No source or reused asset was modified. All required tools are direct and available; no fallback environment or Python extraction was needed.
