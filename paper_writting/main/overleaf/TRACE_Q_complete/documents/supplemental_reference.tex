\section{Complete workflow explanation}
Workflow 1.\allowbreak{}6.\allowbreak{}2: roles, decisions, branches, and limits\par
Documentation prepared from the local normative workflow and role presets, 2026-\allowbreak{}10-\allowbreak{}22.\allowbreak{}\par
This document describes the workflow; it does not execute a paper review.\allowbreak{} Paths below beginning with extraction/\allowbreak{}, checkers/\allowbreak{}, statistics/\allowbreak{}, relationships/\allowbreak{}, screening/\allowbreak{}, verification/\allowbreak{}, or quality/\allowbreak{} are relative to a reviewed package's .\allowbreak{}ai\_\allowbreak{}paper\_\allowbreak{}validation/\allowbreak{}review\_\allowbreak{}1\_\allowbreak{}6\_\allowbreak{}2/\allowbreak{} directory.\allowbreak{} Source references refer to the supplied workflow1.\allowbreak{}6.\allowbreak{}2/\allowbreak{} tree, not to historical execution evidence.\allowbreak{} The accompanying source\_\allowbreak{}locators.\allowbreak{}csv gives exact file and line references; role\_\allowbreak{}decision\_\allowbreak{}matrix.\allowbreak{}csv records the handoffs in tabular form.\allowbreak{}\par
\subsection*{1.\allowbreak{} What the workflow promises}
The unit of work is one supplied paper package: main article plus all supplied supplements, protocol/\allowbreak{}SAP versions, and structured files.\allowbreak{} The goal is to prepare source-\allowbreak{}grounded quantitative reporting candidates for later adjudication.\allowbreak{} It is not a general assessment of clinical value, novelty, misconduct, study validity, or the merits of an alternative analysis.\allowbreak{} Only package evidence is allowed.\allowbreak{} The system does not claim that a candidate is a confirmed scientific problem.\allowbreak{} It does not assign severity or a final correction.\allowbreak{} [S01, S02]\par
There are ten named specialist presets, but eleven mandatory specialist stages: the statistical-\allowbreak{}review preset is instantiated separately for passes 1 and 2.\allowbreak{} The current coordinator is additional, so the minimum specified execution has one coordinator plus eleven distinct specialist runtime IDs.\allowbreak{} A second inclusion-\allowbreak{}screen agent is conditional on new pass-\allowbreak{}2 findings; shards and repairs can add further agents.\allowbreak{} Each mandatory specialist stage must start fresh, even if its scope is explicitly not applicable.\allowbreak{} Fresh agents isolate execution histories; they do not establish independent models or blinded replication.\allowbreak{} All roles use one recorded run model (default gpt-\allowbreak{}6.\allowbreak{}1-\allowbreak{}sol), with medium effort for curation, mapping, numeric/\allowbreak{}cross-\allowbreak{}source checks and reporting, and high effort for the coordinator, statistics, screening, rechecking and auditing.\allowbreak{} This is the current normative specification, not independent proof of what model every historical package used.\allowbreak{} [S03, S04, S05]\par
\subsection*{2.\allowbreak{} Coordinator and source preparation}
The coordinator owns sequencing, exact scope assignments, canonical merging, stable candidate IDs, final classification writeback and completion checks.\allowbreak{} Before scientific work it verifies the routing preflight and role presets, records tools and compute device, hashes direct sources, starts the timing record and execution manifest, and defines a package-\allowbreak{}specific planning target.\allowbreak{} If the default model is unavailable, the specification requires the user to name an exact replacement; it forbids silently choosing a substitute.\allowbreak{} CPU is the default for rendering/\allowbreak{}OCR; GPU use needs an explicit user request.\allowbreak{} These operational requirements describe the actual review pipeline and are not prerequisites for this documentation task.\allowbreak{} [S03, S06]\par
The reuse\_\allowbreak{}asset\_\allowbreak{}curator inventories direct sources and reusable text, OCR, page maps, rendered pages and table/\allowbreak{}workbook extractions.\allowbreak{} It maps every derivative to exact source units, hashes reused artifacts and marks their fitness USABLE, PARTIAL, STALE, DUPLICATE or UNREADABLE.\allowbreak{} It classifies source content as REPORT or PLAN; a protocol packaged as a supplement remains PLAN.\allowbreak{} A mixed bundle needs location-\allowbreak{}level clarification.\allowbreak{} Its outputs are source\_\allowbreak{}inventory.\allowbreak{}md, evidence\_\allowbreak{}asset\_\allowbreak{}inventory.\allowbreak{}md, source\_\allowbreak{}coverage.\allowbreak{}md and the before-\allowbreak{}hash files, with run-\allowbreak{}state initialization coordinated to avoid overlapping writes.\allowbreak{} The curator does not diagnose candidates.\allowbreak{} [S07]\par
Reuse changes the cost of acquisition, not the discovery boundary.\allowbreak{} Old checker outputs, candidate lists, screening/\allowbreak{}classification decisions and reports are preserved but are forbidden scientific inputs for discovery.\allowbreak{} Every source unit has either usable reused coverage or a fresh-\allowbreak{}required assignment: reusable + fresh-\allowbreak{}required = total.\allowbreak{} Every unit must ultimately be mapped: mapped = total.\allowbreak{} Missing extraction software never authorizes dropping pages.\allowbreak{} Available text, targeted rendering/\allowbreak{}OCR and visual inspection must close the scientific coverage gap; any remaining inability must be documented and cannot honestly be called complete coverage.\allowbreak{} A reusable-\allowbreak{}derivative gap can remain a limitation after the direct-\allowbreak{}source scientific gap is closed.\allowbreak{} [S08, S09]\par
The coordinator creates coverage\_\allowbreak{}manifest.\allowbreak{}md before mapping.\allowbreak{} Each row has a disjoint exact scope, stage, unique shard ID, one artifact path and status.\allowbreak{} Candidate-\allowbreak{}stage scope enumerates every assigned C ID; statistical-\allowbreak{}pass scope enumerates S IDs.\allowbreak{} A no-\allowbreak{}applicable scope is explicitly documented COMPLETE, not silently omitted.\allowbreak{} Sharding is allowed only to bound context, never to cap findings.\allowbreak{} The settings prescribe bounds of 200,000 normalized text characters, 32 rendered pages, 120 relationships and 60 candidates per recheck shard; these are operational context bounds, not claims about scientific adequacy.\allowbreak{} [S10, S11]\par
\subsection*{3.\allowbreak{} Two mappers build evidence, without diagnosing candidates}
The main\_\allowbreak{}quantitative\_\allowbreak{}mapper reads the disjoint assigned main-\allowbreak{}paper units.\allowbreak{} It maps counts, denominators, percentages, rates, person-\allowbreak{}time, summaries and dispersion, estimates, intervals, P values, test statistics, standard errors, population/\allowbreak{}time/\allowbreak{}contrast/\allowbreak{}model labels, units, reference directions, figure/\allowbreak{}table labels, footnotes and matching narrative claims.\allowbreak{} It uses reused assets as locators, inspects uncovered direct-\allowbreak{}source units and marks no-\allowbreak{}applicable units explicitly.\allowbreak{} It writes extraction/\allowbreak{}main\_\allowbreak{}quantitative\_\allowbreak{}evidence.\allowbreak{}md or unique parts.\allowbreak{} It neither selects candidates nor samples only primary/\allowbreak{}significant results.\allowbreak{} [S12]\par
The support\_\allowbreak{}quantitative\_\allowbreak{}mapper runs concurrently on disjoint support units: supplements, plans, DOC/\allowbreak{}DOCX, workbooks and CSV.\allowbreak{} It maps the corresponding relationships and matches main-\allowbreak{}paper keys; for workbooks it distinguishes formulas from cached/\allowbreak{}displayed values.\allowbreak{} It reads every assigned plan or administrative unit rather than assuming such pages lack quantitative evidence.\allowbreak{} It writes extraction/\allowbreak{}support\_\allowbreak{}quantitative\_\allowbreak{}evidence.\allowbreak{}md or parts, including a nonempty not-\allowbreak{}applicable record when appropriate.\allowbreak{} [S13]\par
The merged evidence supports stable N001.\allowbreak{}.\allowbreak{}.\allowbreak{} identifiers for numeric/\allowbreak{}reporting relationships and S001.\allowbreak{}.\allowbreak{}.\allowbreak{} identifiers for inferential relationships.\allowbreak{} These relationship IDs are not candidate IDs.\allowbreak{} A relationship can yield a successful reconciliation, a named missing definition, an excluded observation or a finding.\allowbreak{} Both N and S may be attached when separate tracking is useful, but evidence should be cross-\allowbreak{}referenced rather than duplicated.\allowbreak{} [S14]\par
\subsection*{4.\allowbreak{} Three checkers run concurrently after mapping}
The numeric\_\allowbreak{}consistency\_\allowbreak{}reviewer checks participant flow, randomized/\allowbreak{}treated/\allowbreak{}analyzed/\allowbreak{}followed-\allowbreak{}up counts, events, numerator-\allowbreak{}denominator-\allowbreak{}percentage relations, row/\allowbreak{}column/\allowbreak{}subgroup totals, repeated counts and effect-\allowbreak{}measure identity.\allowbreak{} It builds or extends relationships/\allowbreak{}numeric\_\allowbreak{}relationship\_\allowbreak{}inventory.\allowbreak{}md, records reconciled checks, and writes checkers/\allowbreak{}numeric\_\allowbreak{}consistency.\allowbreak{}md.\allowbreak{} Apparent issues passing self-\allowbreak{}screen receive F-\allowbreak{}NUM-\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{} IDs.\allowbreak{} [S15]\par
The cross\_\allowbreak{}source\_\allowbreak{}consistency\_\allowbreak{}reviewer matches population, time, contrast, model, measure, analysis set and precision before comparing values.\allowbreak{} It checks matched results across the abstract, narrative, tables, figures, captions, supplements and structured files; it also compares reported analysis/\allowbreak{}outcomes with plans and examines plan-\allowbreak{}internal statistical elements.\allowbreak{} It compares criterion lists item by item.\allowbreak{} Its output checkers/\allowbreak{}cross\_\allowbreak{}source\_\allowbreak{}consistency.\allowbreak{}md contains F-\allowbreak{}XS-\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{} findings and excluded observations.\allowbreak{} A mismatched analysis population or time point is not a valid numeric comparator merely because the numbers look similar.\allowbreak{} [S16]\par
Statistical pass 1 uses a new high-\allowbreak{}effort statistical\_\allowbreak{}consistency\_\allowbreak{}reviewer.\allowbreak{} It creates the S inventory and checks interval ordering and estimate containment, direction, estimate/\allowbreak{}CI/\allowbreak{}P/\allowbreak{}test compatibility, superiority/\allowbreak{}noninferiority/\allowbreak{}equivalence against stated margins, multiplicity/\allowbreak{}interim/\allowbreak{}stopping rules, and the logic connecting the described method to the reported result.\allowbreak{} Sample size reproduction is in scope when inputs are supplied.\allowbreak{} It must not invent sidedness, degrees of freedom, covariance, variance estimator or an estimand mapping from convention alone.\allowbreak{} Diagnostic approximations are labeled as such.\allowbreak{} Outputs are statistics/\allowbreak{}relationship\_\allowbreak{}inventory.\allowbreak{}md and checkers/\allowbreak{}statistical\_\allowbreak{}pass\_\allowbreak{}1.\allowbreak{}md, with F-\allowbreak{}ST1-\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{} findings and PASS\_\allowbreak{}1\_\allowbreak{}COMPLETE records.\allowbreak{} [S17]\par
Each checker applies the same self-\allowbreak{}screen.\allowbreak{} A qualifying observation becomes a finding, with exact locations, printed values, rule/\allowbreak{}calculation, document roles, focus area, proposed domain, qualifying route, affected result, relevant context and alternatives.\allowbreak{} An apparent issue not emitted is recorded once in an Excluded observations table with a single reason code, but no F ID.\allowbreak{} Checks that simply reconcile belong in relationship records, not the exclusion table.\allowbreak{} This distinction matters because pass 2 and the auditor revisit apparent issues that the first checkers suppressed.\allowbreak{} [S18]\par
\subsection*{5.\allowbreak{} The inclusion decision is a specified rule, with judgment in its application}
The exact logic is: reproduced AND (Route A OR (B1 AND B2 AND B3)).\allowbreak{} Reproduced means reading the exact supplied source correctly and retaining the discrepancy under the stated arithmetic, statistical or logical rule.\allowbreak{} Merely detecting different strings is insufficient.\allowbreak{} [S19]\par
Route A has five always-\allowbreak{}register categories: (1) interval-\allowbreak{}versus-\allowbreak{}P/\allowbreak{}test incompatibility or point estimate outside its interval; (2) a printed sign/\allowbreak{}digit/\allowbreak{}decimal/\allowbreak{}reference-\allowbreak{}direction slip that changes the reading; (3) count-\allowbreak{}denominator-\allowbreak{}percentage incompatibility within one display, including a baseline table; (4) a printed estimate/\allowbreak{}interval not reproduced by a method that does reproduce the other rows of that display; and (5) specified planned-\allowbreak{}versus-\allowbreak{}reported outcome-\allowbreak{}status/\allowbreak{}composite changes, an analysis called prespecified but absent from the supplied plan, or an unreported planned primary/\allowbreak{}key secondary analysis.\allowbreak{} A reproduced Route A observation does not also have to pass Route B.\allowbreak{} Only NOT\_\allowbreak{}REPRODUCED or DUPLICATE\_\allowbreak{}OF\_\allowbreak{}INCLUDED can remove it.\allowbreak{} Category 1 is explicitly exempt from the rounding rule.\allowbreak{} If the source attributes the CI and P value to different analyses, that becomes an alternative interpretation on the card rather than automatic removal under this workflow's policy.\allowbreak{} This is an inclusion policy; it is not a theorem that every retained CI–P pair is scientifically incompatible.\allowbreak{} [S20]\par
Route B requires all three: B1 in the quantitative scope and not peripheral; B2 not immediately resolved by a statistically literate reader's immediate context; B3 plausibly changes interpretation of a named result or the value extracted for evidence synthesis.\allowbreak{} These are source-\allowbreak{}grounded judgment calls, not deterministic string tests.\allowbreak{} The four focus areas are counts/\allowbreak{}denominators, estimate/\allowbreak{}test logic, statistical-\allowbreak{}method logic and planned-\allowbreak{}versus-\allowbreak{}reported statistical design.\allowbreak{} The doubt rule instructs agents to exclude ambiguous wording/\allowbreak{}terminology/\allowbreak{}symbol concerns but register doubtful printed numbers, intervals, P values, counts and plan–report elements for later review.\allowbreak{} This procedural tie-\allowbreak{}breaker does not eliminate the reproduction requirement.\allowbreak{} [S21]\par
Scope is tiered.\allowbreak{} Primary/\allowbreak{}key secondary results, abstract/\allowbreak{}Key Points discrepancies, result misattributions and quantity-\allowbreak{}changing labels can qualify.\allowbreak{} Plan–report comparisons include analysis specification, endpoint definition/\allowbreak{}window/\allowbreak{}hierarchy, outcome status/\allowbreak{}composite components and randomized intervention dose/\allowbreak{}duration.\allowbreak{} Copies of baseline descriptive values, individual-\allowbreak{}time counts, pointers, sites, recruitment calendars and peripheral plan details are normally excluded unless they change a primary/\allowbreak{}key secondary result, analysis-\allowbreak{}population size or decision rule.\allowbreak{} A mismatch inside one baseline count/\allowbreak{}percentage display is nevertheless Route A category 3.\allowbreak{} Apply the explicit Route A exception when it conflicts with a generic exclusion description.\allowbreak{} [S22]\par
Display precision is not raw subtraction or a 5-\allowbreak{}percentage-\allowbreak{}point rule.\allowbreak{} Give every displayed numeric input its half-\allowbreak{}unit rounding interval, propagate those intervals through the stated calculation, and give the displayed comparator its own half-\allowbreak{}unit interval.\allowbreak{} Let g be the nonnegative gap between recomputed and displayed intervals; g = 0 if they overlap.\allowbreak{} For nonzero printed/\allowbreak{}reference value v, define r = g/\allowbreak{}abs(v).\allowbreak{} If g = 0 or r <= 0.\allowbreak{}05, use ROUNDING\_\allowbreak{}OR\_\allowbreak{}DISPLAY\_\allowbreak{}PRECISION.\allowbreak{} If r > 0.\allowbreak{}05, or g > 0 with v = 0, the numeric discrepancy is reproduced, subject to the remaining inclusion logic.\allowbreak{} Two printed copies use the gap between their half-\allowbreak{}unit intervals and a designated reference copy.\allowbreak{} Record both the recomputed interval and r.\allowbreak{} Category 1 interval-\allowbreak{}versus-\allowbreak{}P/\allowbreak{}test conflicts bypass this rounding screen.\allowbreak{} P = 0 or .\allowbreak{}000 by itself is excluded; an independent contradiction is needed.\allowbreak{} [S23]\par
For illustration, two one-\allowbreak{}decimal printed copies 10.\allowbreak{}0 and 10.\allowbreak{}6 have intervals [9.\allowbreak{}95,10.\allowbreak{}05] and [10.\allowbreak{}55,10.\allowbreak{}65], giving g = 0.\allowbreak{}50 and r = 0.\allowbreak{}05 relative to 10.\allowbreak{}0: excluded at the boundary.\allowbreak{} If the second copy is 10.\allowbreak{}7, g = 0.\allowbreak{}60 and r = 0.\allowbreak{}06: the mismatch passes this numeric screen but still needs a qualifying route.\allowbreak{} These are teaching examples, not observations from a paper.\allowbreak{} The 5\% policy is a screening heuristic mandated by this workflow, not a p-\allowbreak{}value, clinical importance cutoff or calibrated detection guarantee.\allowbreak{}\par
Other reason codes are NOT\_\allowbreak{}REPRODUCED, NOTATION\_\allowbreak{}OR\_\allowbreak{}TYPOGRAPHY, TERMINOLOGY\_\allowbreak{}OR\_\allowbreak{}WORDING, MODEL\_\allowbreak{}VERSUS\_\allowbreak{}CRUDE, CONTEXT\_\allowbreak{}RESOLVES, CONDITIONAL\_\allowbreak{}OR\_\allowbreak{}UNREPORTED, PERIPHERAL\_\allowbreak{}COMPARISON, OUT\_\allowbreak{}OF\_\allowbreak{}FOCUS and DUPLICATE\_\allowbreak{}OF\_\allowbreak{}INCLUDED.\allowbreak{} MODEL\_\allowbreak{}VERSUS\_\allowbreak{}CRUDE protects an adjusted/\allowbreak{}model-\allowbreak{}based estimate from being treated as inconsistent merely because it differs from a crude recomputation, unless the source calls it crude/\allowbreak{}unadjusted.\allowbreak{} A missing method detail with no printed contradiction is insufficient.\allowbreak{} Each exclusion has one code; the log is not a severity scale.\allowbreak{} [S24]\par
\subsection*{6.\allowbreak{} Independent screening, deduplication and stable registration}
After all three initial checkers finish, a fresh high-\allowbreak{}effort inclusion\_\allowbreak{}screener rereads every finding's source locations and independently applies the inclusion rule.\allowbreak{} It writes the single screening/\allowbreak{}inclusion\_\allowbreak{}screen.\allowbreak{}md table.\allowbreak{} INCLUDE uses MEETS\_\allowbreak{}THRESHOLD and initially PENDING for the candidate ID; SCREENED\_\allowbreak{}OUT uses one reason code.\allowbreak{} Duplicate findings point to the retained issue and preserve all affected locations.\allowbreak{} No target finding count or comparison with other papers is permitted.\allowbreak{} [S25]\par
Deduplication occurs before stable registration: the same failed rule for the same evident cause across rows/\allowbreak{}outcomes/\allowbreak{}documents is one issue with every affected location.\allowbreak{} Different rules or independent causes warrant separate candidates.\allowbreak{} Several findings can support one included issue.\allowbreak{} The coordinator then assigns C001.\allowbreak{}.\allowbreak{}.\allowbreak{} in source order, writes candidate\_\allowbreak{}ledger.\allowbreak{}md and writes those IDs back to included screening rows.\allowbreak{} F IDs retain checker provenance; C IDs identify durable review objects.\allowbreak{} Later findings are appended without renumbering.\allowbreak{} Once a C ID exists, it is never deleted, merged away or hidden, even if later evidence questions inclusion.\allowbreak{} Zero candidates is valid after complete coverage.\allowbreak{} [S26]\par
\subsection*{7.\allowbreak{} Relationship classification and review-\allowbreak{}domain routing}
At registration the coordinator assigns a provisional relationship type, all relationships, one domain and compared document roles.\allowbreak{} Roles are assigned by content, not filenames.\allowbreak{} P\_\allowbreak{}R means a conflict between REPORT and PLAN and routes to protocol\_\allowbreak{}report; it does not itself imply a protocol violation.\allowbreak{} P\_\allowbreak{}P means solely plan-\allowbreak{}internal conflict and routes to plan\_\allowbreak{}material.\allowbreak{} S\_\allowbreak{}C means between distinct REPORT documents; S\_\allowbreak{}W means within one REPORT document.\allowbreak{} S\_\allowbreak{}C/\allowbreak{}S\_\allowbreak{}W route to statistical\_\allowbreak{}results for counts/\allowbreak{}estimates/\allowbreak{}intervals/\allowbreak{}tests/\allowbreak{}methods, or report\_\allowbreak{}internal\_\allowbreak{}inconsistency when the conflict prevents identifying which outcome/\allowbreak{}time/\allowbreak{}population/\allowbreak{}comparison a number belongs to.\allowbreak{} Mere wording differences are not enough.\allowbreak{} [S27]\par
A candidate involving multiple genuine conflicts lists every relationship and chooses the primary by P\_\allowbreak{}R > P\_\allowbreak{}P > S\_\allowbreak{}C > S\_\allowbreak{}W.\allowbreak{} A document that merely corroborates one side is not another conflict: a protocol confirming the intended value of an internal report discrepancy does not automatically make it P\_\allowbreak{}R.\allowbreak{} Uncertain roles or a potentially disclosed amendment go into Classification ambiguity.\allowbreak{} The rechecker confirms/\allowbreak{}corrects classifications, the auditor audits them, and the coordinator writes the final values back to the ledger.\allowbreak{} This classification routes later review; it is not adjudication or severity.\allowbreak{} [S27, S28]\par
\subsection*{8.\allowbreak{} Recheck and the second statistical pass}
The evidence\_\allowbreak{}rechecker uses a fresh high-\allowbreak{}effort agent for every stable candidate's exact source locations, not OCR as final authority.\allowbreak{} It separately records location found; source and comparator text matched; rule applicable; calculation/\allowbreak{}logic reproduced including rounding; necessary inputs and exact omissions; source-\allowbreak{}grounded alternatives; observation versus inferred explanation; remaining human question; and content-\allowbreak{}based classification.\allowbreak{} PDF locations use truthful \#page=N links; workbook evidence names sheets/\allowbreak{}cells, CSV evidence rows/\allowbreak{}columns and DOCX evidence stable paragraph/\allowbreak{}table locations or a derived PDF page.\allowbreak{} [S29]\par
It assigns exactly one evidence state: reproduced; reproduced\_\allowbreak{}after\_\allowbreak{}transcription\_\allowbreak{}correction if corrected transcription/\allowbreak{}location still supports the discrepancy; or not\_\allowbreak{}reproduced if correct source reading reconciles it.\allowbreak{} A missing definition or failed subcheck is recorded explicitly, not converted into deletion.\allowbreak{} There is no fourth indeterminate evidence-\allowbreak{}state code: unresolved scientific interpretation belongs in the missing-\allowbreak{}input/\allowbreak{}alternative/\allowbreak{}human-\allowbreak{}question fields.\allowbreak{} In particular, inability to reproduce because an input is missing should not be casually equated with evidence that the printed values reconcile.\allowbreak{} The normative state definitions do not fully specify every missing-\allowbreak{}input case; document the factual limitation rather than pretending it is resolved.\allowbreak{} [S30]\par
Statistical pass 2 is a different fresh high-\allowbreak{}effort instance of the statistical reviewer.\allowbreak{} It starts after the complete cross-\allowbreak{}lane ledger, initial screening log and recheck exist, then revisits every S relationship using those artifacts.\allowbreak{} It reconciles numeric/\allowbreak{}cross-\allowbreak{}source implications and checks all checker Excluded observations rows against Route A and the rounding rule.\allowbreak{} It does not re-\allowbreak{}emit an observation already represented in the screening log.\allowbreak{} Every S relationship needs PASS\_\allowbreak{}2\_\allowbreak{}COMPLETE even when there is no finding or a named missing definition prevents mechanical reconciliation.\allowbreak{} Because pass 2 sees earlier outputs, call it a sequential second review, not blinded replication.\allowbreak{} [S31]\par
If no new findings emerge, pass 2 proceeds to audit.\allowbreak{} If it emits F-\allowbreak{}ST2 findings, a different fresh inclusion\_\allowbreak{}screener\_\allowbreak{}pass\_\allowbreak{}2 reads those findings and writes its own working notes; the coordinator appends decisions to the canonical screening table.\allowbreak{} Included issues are appended as new C IDs, classified and rechecked.\allowbreak{} No mandatory third full statistical pass is specified.\allowbreak{} New candidate IDs must be included in subsequent audit/\allowbreak{}report/\allowbreak{}coverage artifacts.\allowbreak{} [S32]\par
\subsection*{9.\allowbreak{} Audit, repair loops and what completion means}
The quality\_\allowbreak{}control\_\allowbreak{}auditor receives the full extraction/\allowbreak{}relationship/\allowbreak{}checker artifacts, all excluded observations, both statistical passes, screen log, ledger, recheck, coverage, source coverage, classifications and execution manifest.\allowbreak{} It audits inclusions and exclusions in both directions, classifications/\allowbreak{}precedence, evidence states, missing evidence-\allowbreak{}card fields, unsupported assumptions, pagination, links, duplication patterns and bounded downstream-\allowbreak{}impact language.\allowbreak{} Every existing C ID receives Inclusion audit: CONFIRMED or QUESTIONED with a reason; neither is a final scientific validity judgment.\allowbreak{} [S33]\par
A finding screened out incorrectly may be rescued by an appended audit row.\allowbreak{} A new auditor finding receives F-\allowbreak{}QA-\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{}; the coordinator registers a new C ID and obtains its recheck.\allowbreak{} Audit history is appended rather than silently overwritten.\allowbreak{} The phrase 'one screening decision per finding' means one initial/\allowbreak{}pass-\allowbreak{}2 decision plus, where needed, an explicit audit revision; the validator permits these paired rows and resolves summaries using the audit row.\allowbreak{} An initially included finding cannot subsequently be screened out.\allowbreak{} A doubtful registered candidate stays in the ledger and report with QUESTIONED or not\_\allowbreak{}reproduced evidence information.\allowbreak{} [S34]\par
There is a wording tension in the auditor preset: it says 'Reject any stable ID' based solely on display-\allowbreak{}zero P, while the same preset forbids deleting/\allowbreak{}suppressing IDs and the canonical contract and validator prohibit changing an included finding to screened-\allowbreak{}out.\allowbreak{} The consistent operational reading is to question its inclusion and retain its stable record; do not describe the workflow as deleting such candidates.\allowbreak{} This is documentation of the tension, not a modification to the workflow.\allowbreak{} [S35]\par
The report\_\allowbreak{}generator assembles every C ID into final\_\allowbreak{}report\_\allowbreak{}1\_\allowbreak{}6\_\allowbreak{}2.\allowbreak{}md, copying classification fields and preserving source evidence, reasoning, calculations, affected result, alternative interpretations, mechanical facts and bounded potential impact.\allowbreak{} It includes the screening/\allowbreak{}domain summaries, full candidate index, limitations, source integrity, agent execution and timing.\allowbreak{} Screened-\allowbreak{}out pre-\allowbreak{}registration findings appear in summary/\allowbreak{}logs, not as candidate cards.\allowbreak{} A zero-\allowbreak{}candidate report still documents scope, coverage, exclusions and limitations.\allowbreak{} Cards say Pending Human Adjudication and contain no human adjudication fields; those belong in the later workbook.\allowbreak{} The coordinator finalizes timing, hashes sources/\allowbreak{}assets again, renders standalone HTML, removes the temporary fallback environment and runs the validator.\allowbreak{} [S36]\par
Correctable validation failures loop back to the responsible artifact/\allowbreak{}coverage repair and are rerendered/\allowbreak{}revalidated until PASS.\allowbreak{} Additional repair agents have distinct IDs and retain their role's model/\allowbreak{}effort class; they cannot stand in for an omitted mandatory stage.\allowbreak{} No fixed retry count, timeout, exponential backoff or promise of eventual success appears in the specification.\allowbreak{} A planning target can be exceeded with reasons; it never permits dropping sources, second passes or candidates.\allowbreak{} If repair needs another model response after the recorded finish, timing and execution metadata are updated.\allowbreak{} Unrepairable missing evidence prevents an honest claim that all mandatory completion gates passed.\allowbreak{} [S37]\par
Mechanical completion requires identical ledger/\allowbreak{}recheck/\allowbreak{}audit/\allowbreak{}report C-\allowbreak{}ID sets, full registered S-\allowbreak{}ID coverage in both passes, complete classification, resolved local links, unchanged source/\allowbreak{}reused hashes, prescribed fresh-\allowbreak{}agent manifests, tooling cleanup and a valid standalone HTML report.\allowbreak{} The validator enforces file/\allowbreak{}schema/\allowbreak{}set/\allowbreak{}count/\allowbreak{}link/\allowbreak{}hash/\allowbreak{}manifest properties and checks declared source-\allowbreak{}coverage arithmetic.\allowbreak{} Its S-\allowbreak{}pass checks look for relationship IDs in both pass artifacts and completion markers in the inventory.\allowbreak{} It does not independently read every source page, rediscover missing relationships or prove that the mathematical/\allowbreak{}scientific reasoning is correct.\allowbreak{} Therefore PASS means the machine-\allowbreak{}checkable contract passed, not perfect coverage in a semantic sense, calibrated sensitivity/\allowbreak{}specificity, clinical importance, absence of missed issues or successful human adjudication.\allowbreak{} Those stronger claims need separate evaluation.\allowbreak{} [S38]\par
\subsection*{10.\allowbreak{} Intended human responsibility versus the supplied completed-\allowbreak{}run record}
The intended endpoint of Workflow 1.\allowbreak{}6.\allowbreak{}2 is a reviewable evidence package.\allowbreak{} Humans decide the ultimate disposition and substantive interpretation; the workflow's inclusion state, evidence state and inclusion audit do not substitute for that responsibility.\allowbreak{} The report deliberately leaves adjudication fields to a later workbook.\allowbreak{} [S39]\par
However, reviewer\_\allowbreak{}runs\_\allowbreak{}raw/\allowbreak{}README.\allowbreak{}md explicitly says the supplied eight completed v2.\allowbreak{}4.\allowbreak{}1 workbooks were produced by Claude Opus 5.\allowbreak{}5 high-\allowbreak{}effort agent sessions, under labels R\_\allowbreak{}A and R\_\allowbreak{}Bulun, and that no person reviewed any candidate.\allowbreak{} Eight original sessions were followed by two 2025 addendum sessions; the latter's 24 candidates per label were merged into the 2025 files.\allowbreak{} Each reviewer session worked alone.\allowbreak{} The reviewers read source PDFs before each candidate card and could inspect the supplied workflow scope, so their task is a post-\allowbreak{}pipeline review with access to cards, not a blind independent search of an unflagged paper set.\allowbreak{} [S40]\par
