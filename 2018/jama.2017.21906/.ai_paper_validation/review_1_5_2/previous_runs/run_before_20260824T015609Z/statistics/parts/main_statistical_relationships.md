- Table 3 uses mixed-effects logistic regression; each cluster-adjusted model accounts for within-hospital clustering and each primary model also accounts for temporal trends. Its OR is intervention compared with control and its RD is intervention minus control.
- Figure 3 is adjusted for within-hospital clustering and temporal trends. It presents intervention then control counts/rates, adjusted difference, and adjusted odds ratio; marker size represents precision.
