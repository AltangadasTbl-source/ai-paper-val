### P1-01 — Reversed confidence-interval endpoint order in unclustered all-patient first-attempt duration

- **Candidate category:** Statistical reporting inconsistency.
- **Exact source locations:** DOC-001, [PDF p. 7, Table 3](../../../jama_driver_2018_oi_180054.pdf#page=7). Supporting distinct-model context: DOC-003, [PDF p. 2, eTable 1](../../../joi180054supp2_prod.pdf#page=2).
- **Printed source evidence:** For “All patients (N = 757) — First-attempt duration, median (IQR), s,” Table 3 prints Bougie `38 (29 to 51)`, ETT+stylet `36 (25 to 54)`, difference `1 (4 to −1)`, and `P Value .24`.
- **Comparator:** The same printed interval endpoints are `4` and `−1`; a conventional lower-to-upper interval requires the first endpoint not exceed the second. The separately clustered eTable 1 reports `1 s (−1 s to 4 s), P=0.95` for the same outcome/population but explicitly recalculates its inferential columns for physician clustering.
- **Reproducible rule:** In any displayed interval in lower-to-upper notation `estimate (L to U)`, endpoint ordering requires `L <= U`. Here `4 > −1`; the printed unclustered Table 3 interval violates that ordering. This observation does not use the clustered result to calculate or replace an unclustered interval.
- **Direct observation:** DOC-001 visibly prints `1 (4 to −1)` in the all-patient duration row.
- **Diagnostic inference (labelled):** The positive estimate and P=.24 are compatible with an interval spanning 0, and DOC-003 prints the endpoints in the opposite order under a different clustered model. These facts make endpoint transposition a possible explanation, but do not establish the intended unclustered interval.
- **Alternative source-grounded interpretations:** A table-order/typesetting error is possible; the source does not state whether its convention lists confidence limits in another order. The clustered eTable is not a numerical replacement because its difference/P/interaction columns were recalculated for clustering.
- **Exact human question:** Does the unclustered Table 3 all-patient duration result have its confidence-interval endpoints transposed, and if so, what were the analysis-specific unclustered 95% limits as generated by the reported Hodges-Lehmann procedure?
