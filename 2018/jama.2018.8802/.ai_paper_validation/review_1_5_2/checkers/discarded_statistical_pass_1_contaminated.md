### SCAND001 — In-hospital-death absolute-difference P value conflicts with its displayed 95% CI

- **Category:** Statistical reporting inconsistency.
- **Exact source location:** DOC-001, [jama_wang_2018_oi_180070.pdf — PDF p. 8](<../../../jama_wang_2018_oi_180070.pdf#page=8>), Table 3, `Death — In hospital`.
- **Direct observation:** The adjusted absolute-difference block prints `-0.7% (95% CI, -1.1 to 0.2)` and its adjacent P-value column prints `.009`. A separate HR block prints `0.96 (95% CI, 0.90 to 1.02)` with P=.14.
- **Consistency rule:** The article supplies a two-sided testing statement and labels the first block as an adjusted 95% CI and its P value for the same death contrast. At printed precision, the absolute-difference CI includes its null (0), while the same-block P=.009 is below .05.
- **Diagnostic calculation (not a replacement analysis):** CI midpoint = (-1.1 + 0.2)/2 = -0.45 percentage points; half-width = (0.2 - -1.1)/2 = 0.65; approximate SE = 0.65/1.96 = 0.33; approximate |z| = 0.45/0.33 = 1.36. This diagnostic is not an exact P reconstruction.
- **Missing definition:** The package does not identify the absolute-difference estimator, variance estimator, degrees of freedom, covariance, or exact CI/P inversion rule.
- **Alternative source-grounded interpretation:** The P value may have been paired with a differently constructed test than the displayed CI, or a table entry may be misaligned/transcribed; the separate HR/P pair does not resolve the absolute-difference pair.
- **Human question:** Does `.009` belong to the displayed in-hospital absolute difference, and if so which supplied analysis rule reconciles it with `-1.1 to 0.2`? If it does not, which printed table value is intended?
