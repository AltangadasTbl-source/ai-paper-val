# Numeric Consistency Review

## Scope and method

Fresh source-first review of every canonical numeric relationship `N001`--`N073` and of the numerical implications of every canonical statistical relationship `S001`--`S032`.  I used only the supplied PDFs and their fresh native/layout evidence. Checks included exact count and subtotal reconciliation, percentage recomputation (usual display tolerance: 0.05 percentage points for one-decimal percentages), complement/denominator checks, interval ordering, repeated-value checks, and direct risk-difference/risk-ratio checks. A numerical result is not a candidate merely because a displayed P value is zero or rounded; no such candidate was registered.

`No candidate` means the printed relationship reconciled within its printed precision, used a stated different analysis population, or was a definition/procedural quantity for which no incompatible numerical assertion was printed.

## Candidate observations (no stable IDs or dispositions)

### NC-01 — Printed IQR lower endpoint exceeds printed median

- **Relationships / location:** `N024`; DOC-001, Table 1, PDF page 5 (`jama_cooper_2018_oi_180132.pdf#page=5`).
- **Direct observation:** the normothermia Injury Severity Score is printed as median **20.0** with IQR **20.5-35.0**.
- **Rule/calculation:** for an ordinary median and 25th--75th percentile IQR, `Q1 <= median <= Q3`. Here `20.5 > 20.0`, a direct ordering violation of **0.5 ISS points**. This uses no rounding tolerance: rounding cannot reverse the order where both values are printed to one decimal place unless their unrounded values cross, which is incompatible with the displayed lower endpoint being greater than the displayed median.
- **Alternative interpretation:** the table may contain a transposed/mistyped digit or may use a nonstandard interval convention, but the table labels it “median (IQR)” and its footnote defines the ISS scale rather than another interval convention.
- **Quality-control relevance:** if copied without source checking, the impossible summary ordering could create an ambiguous baseline-severity value in later tabular extraction.
- **Human question:** What are the intended normothermia ISS median and IQR endpoints, and should the Table 1 display be corrected?

### NC-02 — Opposite signs for the same primary risk difference

- **Relationships / location:** `N028`; DOC-001 abstract PDF page 1; Results narrative PDF page 5; Table 2 PDF page 7 (`jama_cooper_2018_oi_180132.pdf#page=1`, `#page=5`, `#page=7`).
- **Direct observation:** all locations print **117/240 (48.8%)** hypothermia and **111/226 (49.1%)** normothermia. The abstract calls the risk difference **0.4% (95% CI -9.4% to 8.7%)**, whereas the narrative and Table 2 print **-0.4 percentage points (95% CI -9.4 to 8.7)**.
- **Rule/calculation:** `117/240 - 111/226 = 0.48750 - 0.49115 = -0.00365`, or **-0.365 percentage points**, which rounds to **-0.4 pp**. Tolerance for values printed to one decimal percentage point is +/-0.05 pp, so `+0.4` is not a permissible rounding of the direction.
- **Alternative interpretation:** the unsigned abstract value may have been intended as an absolute difference, but it is labelled “risk difference” and presents the same signed CI whose point estimate agrees with the negative narrative/table value.
- **Quality-control relevance:** the sign controls the stated direction of the primary absolute effect in abstract-level data extraction.
- **Human question:** Should the abstract risk difference have a leading minus sign, or was an explicitly absolute difference intended and labelled incorrectly?

### NC-03 — Main-table bleeding effect/P values do not match their printed counts or the supplied supplementary table

- **Relationships / locations:** `N034`, `N064`; DOC-001 Table 2 PDF page 7 and DOC-003 eTable 6 PDF page 10 (`jama_cooper_2018_oi_180132.pdf#page=7`; `joi180132supp2_prod.pdf#page=10`). The linked statistical implications are `S008` and `S023`.
- **Direct observation:** for new/increased intracranial bleeding, the main table prints **47/260 (18.1%)** versus **37/240 (15.4%)**, RD **2.7 (-3.9 to 9.2)**, RR **1.23 (0.43-3.5)**, **P=.70**. For significant extracranial bleeding it prints **8/260 (3.1%)** versus **6/240 (2.5%)**, RD **0.6 (-2.3 to 3.5)**, RR **1.17 (0.79-1.74)**, **P=.43**. Supplied eTable 6 prints the same two count pairs but **P=.43** for intracranial and **P=.70** for extracranial.
- **Rule/calculation:** the direct count ratios are `(47/260)/(37/240)=1.173` (rounds **1.17**) and `(8/260)/(6/240)=1.231` (rounds **1.23**). Thus the main table’s two displayed RRs are paired with the opposite count rows. The supplied eTable 6 P values are also paired oppositely to the main Table 2 P values. The main-table RRs/CI/P values exactly have the appearance of having been interchanged between the two bleeding rows; no calculation from the printed data supports associating RR 1.23 with the intracranial count pair or RR 1.17 with the extracranial count pair.
- **Tolerance:** RR comparison uses ordinary two-decimal display rounding (+/-0.005); the discrepancies are 0.057 and 0.061, far beyond tolerance. The P-value observation is direct cross-document disagreement, not a recalculated P-value claim.
- **Alternative interpretation:** different analysis populations could in principle produce distinct estimates, but both Table 2 rows state intention-to-treat and both sources print the identical n/N pairs. No alternate population is printed for the discordant P values.
- **Quality-control relevance:** the effect magnitude, confidence interval, and inferential value for each named bleeding outcome can be misattributed in evidence synthesis.
- **Human question:** Were the RR/CI/P entries for intracranial and extracranial bleeding transposed in Table 2, and which values should be attached to each outcome?

### NC-04 — As-treated CT table reverses count and percentage formatting in one cell

- **Relationships / location:** `N069`; DOC-003 eTable 10, PDF page 18 (`joi180132supp2_prod.pdf#page=18`).
- **Direct observation:** eTable 10 is headed “No. (%)” with normothermia `n=196`. For “Evacuated mass lesion V,” the hypothermia cell is **44 (33.1)**, but the normothermia cell is printed **34.7 (68)**. The other normothermia CT categories are 3, 108, 15, and 2, so **3+108+15+68+2=196** and `68/196*100=34.69%`, which rounds to **34.7%**.
- **Rule/calculation:** under the table’s declared `No. (%)` format, the expected display is **68 (34.7)**. The printed cell has that pair reversed. This is a direct label/order inconsistency, not a rounding issue.
- **Alternative interpretation:** it could be an isolated typographical inversion; the values themselves are internally recoverable from the subgroup total.
- **Quality-control relevance:** if mechanically extracted under the printed header order, the cell could be recorded as a noninteger count and a 68% value in a later evidence table.
- **Human question:** Should the normothermia evacuated-mass-lesion-V cell read “68 (34.7)”?

### NC-05 — Abstract male count conflicts with its stated cohort and Table 1

- **Relationships / location:** `N004`, `N020`; DOC-001 abstract PDF page 1 and Table 1 PDF page 5 (`jama_cooper_2018_oi_180132.pdf#page=1`, `#page=5`).
- **Direct observation:** the abstract states that **500** participants provided ongoing consent and reports **402 men (80.2%)**. Table 1, explicitly for the intention-to-treat population `n=260` and `n=240` (total **500**), prints men as **207 (79.6%)** and **194 (80.8%)**, totaling **401 men (80.2%)**.
- **Rule/calculation:** `402/500*100=80.4%`, not 80.2% at one-decimal precision; `401/500*100=80.2%`, exactly matching the Table 1 count and both displayed table percentages. A 402 count can yield 80.2% only with an unprinted denominator around 501, incompatible with the abstract’s stated ongoing-consent count and the 500-person Table 1 population.
- **Tolerance:** one-decimal percentage rounding permits +/-0.05 percentage points; 80.4% is 0.2 percentage points from 80.2%.
- **Alternative interpretation:** the abstract’s count may be a typographical error, or a different sex denominator may have existed but is not reported. The Table 1 population label and its complete sex subtotal provide the direct competing value.
- **Quality-control relevance:** an abstract-only extractor could copy a male count that does not reconcile with the supplied table and denominator if the candidate is confirmed.
- **Human question:** Is the abstract male count intended to be 401 rather than 402, or was a distinct sex-analysis denominator intended and omitted?
