Prepared for four separate Codex windows. This folder is inside the repository's existing `ignorance_documents` directory (plural). Each year contains a complete local workflow, AGENTS.md, a ready-to-paste launch prompt, a standard-library Python preflight script and the inspected baseline inventory. No v.2.3.1 workbooks are built by this planning task.

The cohort contains 45 papers and 412 unique candidates; each reviewer reviews all 412 independently. The intended release is eight files: one R_A and one R_B primary-review workbook per year. Separate files prevent reviewers from seeing one another's answers; distribute only the assigned file. Both see the same baseline AI suggestions and evidence, as in v.2.1.5.3.

Preserve the familiar primary-check layout, dropdown meanings, applicability rules and steps. Remove sequential checker/snapshot/consensus stages. Excel formulas provide all ongoing validation and results; Python is a construction tool only. Each year builds and validates locally with no shared mutable outputs.

The inspected v.2.1.5.3 release has no locks. For v.2.3.1, only a documented fixed rule-default reference area may be protected without a password. Reviewer input cells, including domain-dependent judgment fields, remain editable. Macro-free Excel cannot dynamically change cell protection when a domain changes; formula checks and shading handle applicability.

A completed `discuss` entry remains allowed in primary review and is reported as unresolved. Paper outcome counts remain blank while any row is unfinished or unresolved; neither reviewer needs a consensus discussion to submit their independent review.

Read a year's START_HERE.md and paste its prompt into Codex opened in that exact folder. The sessions can run concurrently; each is restricted to its own year folder. The final Excel smoke test must be reported as performed or pending, never inferred from merely writing XLSX formulas.
