Construction completed using Python 3.12.3, openpyxl 3.1.5 and et_xmlfile 2.0.0 in the local .venv. Validation date: 2026-09-18. No Excel or LibreOffice engine is installed. These files are constructed and statically validated; they are **not fully validated in desktop Excel**.

## Executed checks

- The read-only preflight inventory matches baseline_inventory.json exactly. All seven reference hashes still match. Each role has 10 C_ sheets and 119 unique keys in baseline order.
- Candidates, Evidence, Links and Relations match the annual baseline and the 2018 source-catalog subset cell-for-cell. A–C, suggested E and the original H–L default formulas match. Dispositions, notes and reviewer identity are blank; F=no. The role files differ only in their own role metadata.
- Each file contains 2,347 parsed internal formulas; maximum formula length is 2,057 characters, below Excel's 8,192-character limit. Full automatic recalculation is configured. Formula references resolve to existing sheets and cells; no formula error literals were found. This is not a claim about recalculated Excel values.
- All 644 hyperlinks per file resolve: 129 internal navigation links and 515 original-source links. Targets were checked again from release/. Original href cell values are preserved. No external workbook links, queries, connections, macros, stale names, obsolete workflow or other reviewer data remain.
- Primary layout, 18 columns, wrapped text, navy header, frozen panes, editable suggestions, dropdown option lists, input colors, conditional formatting and empty hidden M–Q were inspected programmatically. Dropdowns expose their arrows and have valid list lengths. No visual rendering was available.
- Serialized cell/style protection was inspected directly, including default styles for unused cells. All are explicitly unlocked and formulas are visible. **Protected ranges: NONE.** There are no passwords or worksheet/workbook locks. Rule_defaults is a visible, unlocked reference.
- 42 aggregate static checks and 105 synthetic assertions passed per full validation run. Detailed assertions and release hashes are in validation_report.release.json. The synthetic probe evaluates the actual emitted formulas using a deliberately limited custom Python interpreter; it is not a certified Excel-compatible engine.
- Synthetic assertions cover retained domains, required/optional blank and invalid entries, all optional codes, exclude/discuss, whitespace identity, pasted invalid options, inactive stale judgments, domain/disposition changes, optional clearing, manual completion reset, forbidden completion flags, missing/duplicate/unknown keys, missing-key propagation, and independent copies.
- Outcome checks cover confirmed/probable substantive statistical findings, minor/indeterminate/not-issue cases, internal inconsistency, P_R/P_P precedence, excluded/unfinished/discuss records and paper gating. The complete 119-row synthetic fixture produces 68 primary_temporal, 29 secondary_temporal, 11 protocol_descriptive and 11 plan_descriptive outcomes; all 10 paper totals reconcile. These are TEST answers, not research findings.
- All formulas in the full-year synthetic copy were evaluated by the limited probe. Whole-row reordering retained candidate-key mapping. A one-candidate fixture passed lookup/readiness checks. Synthetic XLSX files were saved/reopened with openpyxl; that does not establish Excel recalculation. No synthetic answers are in release templates.

The builder also passed four refusal checks: non-2018 year, release output path, existing staging workbooks, and an output path outside this year. See tests/builder_guard_report.json.
