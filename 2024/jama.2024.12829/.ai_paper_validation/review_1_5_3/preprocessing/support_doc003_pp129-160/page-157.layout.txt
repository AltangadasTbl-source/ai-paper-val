2696   10.2 Event Rates

2697   The number of people and person-time of events should be recorded in detail and

2698   showing the event rate of each treatment group in summary statement.

2699   The event rate for each treatment group will be calculated as: the sum of number of event

2700   for all the patients / the sum of number of treatment periods for all the patients.

2701   10.3 Time to Event Analysis

2702   Differences between treatments in the risk of any stroke (ischemic or haemorrhagic)

2703   event or combined vascular events during follow-up were assessed using standard

2704   Kaplan-Meier time-to-event approaches. The time to the first event was used in the model

2705   when there were multiple events of the same type. Patients were considered censored at

2706   the time of study termination or death if there were no events occurred during the study.
