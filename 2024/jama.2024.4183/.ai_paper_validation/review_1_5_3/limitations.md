# Limitations and Missing Definitions

The supplied package contains published PDFs only. It does not contain participant-level data, posterior draws, table-generation files, simulation code, protocol-version crosswalks, or document-version history. These absences prevent selection of authoritative corrections where more than one source-grounded explanation remains possible.

C005 depends on the unresolved grammatical scope of the abstract parenthetical. C010 is limited to the reproducible beta-mean comparison because the source does not define the interval-to-beta linkage. C011 is conditional on common simulation realizations and a common detection definition. Several cross-reference and interval candidates likewise require a human decision about intended table numbering, reference orientation, or output version. No limitation establishes that any paper conclusion changed.
