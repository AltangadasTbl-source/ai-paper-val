Comparators: [jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 6 (journal p. 1528), Table 2](../jama_engelter_2025_oi_250066_1761597796.45511.pdf#page=6), “Prespecified adverse events of interest”; and [jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 7 (journal p. 1529), *Adverse Events* continuation](../jama_engelter_2025_oi_250066_1761597796.45511.pdf#page=7).
- **Source evidence:** Supplement header: Overall `145`, Placebo `67`, Levodopa `79` events. Intensity: mild `58`, moderate `86`, severe `2`. Outcome: ongoing `1`, resolved with sequelae `29`, resolved without sequelae `116`. Drug relation: certain `2`, possible `66`, probably `23`, unassessable `2`, unlikely `39`, unrelated `14`. Main article: “A total of 146 prespecified adverse events of interest” and arm counts `79` and `67`.
- **Reported-versus-comparator comparison:** Reported supplement overall `145` events versus `146` from the two supplement arms, each supplement classification partition, and the main article.

**Reasoning procedure**

1. Treat the placebo and levodopa columns as the two displayed treatment-arm components of the Overall column: `67 + 79 = 146` events.
2. Treat intensity categories as mutually exclusive displayed classifications: `58 + 86 + 2 = 146` events.
3. Treat outcome categories as the displayed outcome partition: `1 + 29 + 116 = 146` events.
4. Treat drug-relation categories as the displayed relation partition: `2 + 66 + 23 + 2 + 39 + 14 = 146` events.
5. Compare all four independently reproduced totals with the printed header: `146 − 145 = 1` event.
6. Counts are integers, so rounding tolerance is `0` events. The repeated `146` is also directly observed in the main-article narrative; it is not derived solely from the supplement.

- **Existing supported conclusion:** The supplement's overall `n=145` is one event below every displayed reconstruction and the main-article total.
- **Limit on interpretation:** The evidence does not identify a wrong arm count or classification value and does not establish which individual event, if any, caused the header discrepancy.
- **Bounded impact:** A one-event inconsistency in the supplement header; the displayed arm and classification totals are not shown to be wrong.
- **Human verification instruction:**

  1. Check the source table shell or event listing used to produce eTable 6. A total of `146` with unchanged arm and category values confirms a header-only correction.
  2. If the source total is `145`, identify and document the specific arm/category value that must change; that result resolves the discrepancy by a component correction rather than a header correction.

### C03 — Onset-to-randomization timing differs by 4 to 5 median days

- **Evidence status:** Verified; retained by critic.
- **Category / severity:** Cross-document inconsistency / Minor.
- **Issue statement:** The main article reports a median of 3 days from stroke onset to randomization in each arm, while the identically described supplement row reports 7 days for levodopa and 8 days for placebo.
- **Exact source locations:** [jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 4 (journal p. 1526), Table 1 continuation](../jama_engelter_2025_oi_250066_1761597796.45511.pdf#page=4), row “Time from stroke onset to randomization, median (IQR), d.” Comparator: [joi250066supp3_prod_1761597796.4701.pdf, PDF p. 11, eTable 1 continuation](../joi250066supp3_prod_1761597796.4701.pdf#page=11), row “Median time from stroke onset to randomization [IQR].” The supplement row does not itself print a day suffix; its values are compared to the main article's explicitly day-denominated row.
- **Source evidence:** Main article levodopa `3.0 (2.0–5.0)` days and placebo `3.0 (2.0–5.0)` days. Supplement Overall `7 [5, 10]`, placebo `8 [5, 10]`, levodopa `7 [5–11]`.
- **Reported-versus-comparator comparison:** Levodopa median `7` versus `3.0`; placebo median `8` versus `3.0`.

**Reasoning procedure**

1. Match the descriptive construct (time from stroke onset to randomization), statistic (median with IQR), and treatment arms.
2. Calculate the displayed median differences: levodopa `7 − 3.0 = 4.0` days; placebo `8 − 3.0 = 5.0` days.
3. Examine display precision. A value shown as `3.0` to the nearest 0.1 day would ordinarily represent approximately `2.95` to `<3.05`; a whole-day value `7` would ordinarily represent approximately `6.5` to `<7.5`. Those intervals do not overlap. The same is true for `3.0` versus `8`.
4. The IQRs also differ: both main-article arms `2.0–5.0`, versus supplement placebo `5–10` and levodopa `5–11`. This is a direct observation, not used to infer a replacement value.

- **Existing supported conclusion:** The package reports incompatible arm-specific timing descriptions that cannot be explained by displayed precision.
- **Limit on interpretation:** The supplied tables do not establish which values or variable derivation are correct and do not demonstrate any change in a treatment-effect estimate.
- **Bounded impact:** A 4-day levodopa and 5-day placebo difference in reported medians, with different IQRs.
- **Human verification instruction:**

  1. Compare the variable definition, unit, population, and time origin in the main-table and supplement-table production specifications.
  2. Recalculate arm-specific median and IQR values from the locked analysis dataset.
  3. Matching recalculated values to one table confirms which report should be aligned; a difference in variable definition resolves the issue only if that distinction is explicitly added to the reports.

(%),” Placebo and Levodopa columns.

**Reasoning procedure**

1. Reproduce the main-article placebo rate: `(52 ÷ 270) × 100 = 19.259...%`, which rounds to `19%` at whole-percent precision.

4. Calculate the unrounded rate difference: `(52 − 51) ÷ 270 × 100 = 0.37037...` percentage points.
5. Whole-percent rounding makes both rates display as `19%`; it does not reconcile the exact numerators. Denominators agree and `270 + 276 = 546`, matching the supplement total N.

- **Existing supported conclusion:** Each document's percentage is internally compatible with its own numerator, but the placebo numerators conflict by one participant.
- **Limit on interpretation:** The package does not establish whether `51` or `52` is the validated count and does not show an error in the levodopa result.
- **Bounded impact:** One placebo participant and approximately `0.37` percentage points in the unrounded placebo rate.
- **Human verification instruction:**

  1. Check the final PRAI derivation for the `270` placebo respondents, including the coding of “no” and “no relevant improvement.”
  2. A source count of `51` confirms eTable 4; `52` confirms the main text. Align the other source and its percentage.
  3. Confirm the levodopa `51/276` and combined denominator `546` remain unchanged unless the source data establish otherwise.
