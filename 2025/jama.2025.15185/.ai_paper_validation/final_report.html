C01 — eTable 6 overall adverse-event total is one event short

  • Evidence status: Verified; retained by critic.
  • Category / severity: Arithmetic inconsistency / Minor.
  • Issue statement: The results supplement reports 145 prespecified adverse events overall, although both arm totals and every displayed classification block sum to 146.
  • Exact source locations: joi250066supp3_prod_1761597796.4701.pdf, PDF p. 17, eTable 6, columns Overall, Placebo, and Levodopa, rows n, AE intensity, AE outcome, and Drug relation. Comparators: jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 6 (journal p. 1528), Table 2, “Prespecified adverse events of interest”; and jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 7 (journal p. 1529), Adverse Events continuation.
  • Source evidence: Supplement header: Overall 145, Placebo 67, Levodopa 79 events. Intensity: mild 58, moderate 86, severe 2. Outcome: ongoing 1, resolved with sequelae 29, resolved without sequelae 116. Drug relation: certain 2, possible 66, probably 23, unassessable 2, unlikely 39, unrelated 14. Main article: “A total of 146 prespecified adverse events of interest” and arm counts 79 and 67.
  • Reported-versus-comparator comparison: Reported supplement overall 145 events versus 146 from the two supplement arms, each supplement classification partition, and the main article.

Reasoning procedure

  1. Treat the placebo and levodopa columns as the two displayed treatment-arm components of the Overall column: 67 + 79 = 146 events.
  2. Treat intensity categories as mutually exclusive displayed classifications: 58 + 86 + 2 = 146 events.
  3. Treat outcome categories as the displayed outcome partition: 1 + 29 + 116 = 146 events.
  4. Treat drug-relation categories as the displayed relation partition: 2 + 66 + 23 + 2 + 39 + 14 = 146 events.
  5. Compare all four independently reproduced totals with the printed header: 146 − 145 = 1 event.
  6. Counts are integers, so rounding tolerance is 0 events. The repeated 146 is also directly observed in the main-article narrative; it is not derived solely from the supplement.

  • Existing supported conclusion: The supplement's overall n=145 is one event below every displayed reconstruction and the main-article total.

  • Limit on interpretation: The evidence does not identify a wrong arm count or classification value and does not establish which individual event, if any, caused the header discrepancy.

  • Bounded impact: A one-event inconsistency in the supplement header; the displayed arm and classification totals are not shown to be wrong.

  • Human verification instruction:

    1. Check the source table shell or event listing used to produce eTable 6. A total of 146 with unchanged arm and category values confirms a header-only correction.
    2. If the source total is 145, identify and document the specific arm/category value that must change; that result resolves the discrepancy by a component correction rather than a header correction.
    3. Confirm that the main-article text and Table 2 remain aligned with the verified source total.

C02 — Supplementary stroke-type arm counts do not reconcile

  • Evidence status: Verified; retained by critic.
  • Category / severity: Cross-document inconsistency / Minor.
  • Issue statement: The supplement reports levodopa stroke-type counts of 263 ischemic and 44 hemorrhagic, whereas the main article reports 260 and 47; only the main-article arm values reproduce the supplement's Overall counts.
  • Exact source locations: joi250066supp3_prod_1761597796.4701.pdf, PDF p. 10, eTable 1, rows “Stroke ischemic – No. (%)” and “Stroke hemorrhagic – No. (%)”, columns Overall, Placebo, and Levodopa. Comparator: jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 4 (journal p. 1526), Table 1, “Type of stroke,” rows Ischemic and Hemorrhagic, Levodopa and Placebo columns.
  • Source evidence: Supplement ischemic 519 (85.1%) / 259 (85.5%) / 263 (85.7%); hemorrhagic 91 (14.9%) / 44 (14.5%) / 44 (14.3%), ordered Overall/Placebo/Levodopa. Main article levodopa/placebo: ischemic 260 (84.7%) / 259 (85.5%); hemorrhagic 47 (15.3%) / 44 (14.5%).
  • Reported-versus-comparator comparison: The placebo counts agree across documents. The levodopa counts differ by three in opposite directions: ischemic 263 versus 260, hemorrhagic 44 versus 47.

Reasoning procedure

  1. Reconstruct the supplement's ischemic Overall from its arms: 259 + 263 = 522, which is 522 − 519 = 3 above the displayed Overall.
  2. Reconstruct the supplement's hemorrhagic Overall: 44 + 44 = 88, which is 91 − 88 = 3 below the displayed Overall.
  3. Reconstruct using main-article arms: ischemic 259 + 260 = 519; hemorrhagic 44 + 47 = 91. Both exactly equal the supplement's Overall counts.
  4. Confirm within-arm exclusivity at the displayed two-category level. Supplement levodopa: 263 + 44 = 307; main-article levodopa: 260 + 47 = 307. Thus each document preserves the randomized levodopa total while assigning three participants differently between the displayed categories.
  5. Counts are integers; rounding tolerance is 0 participants. Percentages corroborate their respective printed numerators but cannot resolve which source classification is correct.

  • Existing supported conclusion: The arm-specific stroke-type values conflict across the documents and the supplement's own arm values do not reproduce its Overall column.

  • Limit on interpretation: Without participant-level classification data or final production output, the evidence does not prove actual participant misclassification or establish which document is correct.

  • Bounded impact: Three levodopa participants differ in each of two complementary categories; the levodopa total remains 307.

  • Human verification instruction:

    1. Check the final randomized stroke-type dataset or validated baseline table output for all 307 levodopa participants.
    2. A verified split of 260 ischemic and 47 hemorrhagic confirms the main-article arm cells and supplement Overall cells; a different validated split identifies the required alternative correction.
    3. Confirm that revised counts and percentages sum to 307 in the levodopa arm and to 610 overall.

C03 — Onset-to-randomization timing differs by 4 to 5 median days

  • Evidence status: Verified; retained by critic.
  • Category / severity: Cross-document inconsistency / Minor.
  • Issue statement: The main article reports a median of 3 days from stroke onset to randomization in each arm, while the identically described supplement row reports 7 days for levodopa and 8 days for placebo.
  • Exact source locations: jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 4 (journal p. 1526), Table 1 continuation, row “Time from stroke onset to randomization, median (IQR), d.” Comparator: joi250066supp3_prod_1761597796.4701.pdf, PDF p. 11, eTable 1 continuation, row “Median time from stroke onset to randomization [IQR].” The supplement row does not itself print a day suffix; its values are compared to the main article's explicitly day-denominated row.
  • Source evidence: Main article levodopa 3.0 (2.0–5.0) days and placebo 3.0 (2.0–5.0) days. Supplement Overall 7 [5, 10], placebo 8 [5, 10], levodopa 7 [5–11].
  • Reported-versus-comparator comparison: Levodopa median 7 versus 3.0; placebo median 8 versus 3.0.

Reasoning procedure

  1. Match the descriptive construct (time from stroke onset to randomization), statistic (median with IQR), and treatment arms.
  2. Calculate the displayed median differences: levodopa 7 − 3.0 = 4.0 days; placebo 8 − 3.0 = 5.0 days.
  3. Examine display precision. A value shown as 3.0 to the nearest 0.1 day would ordinarily represent approximately 2.95 to <3.05; a whole-day value 7 would ordinarily represent approximately 6.5 to <7.5. Those intervals do not overlap. The same is true for 3.0 versus 8.
  4. The IQRs also differ: both main-article arms 2.0–5.0, versus supplement placebo 5–10 and levodopa 5–11. This is a direct observation, not used to infer a replacement value.

  • Existing supported conclusion: The package reports incompatible arm-specific timing descriptions that cannot be explained by displayed precision.

  • Limit on interpretation: The supplied tables do not establish which values or variable derivation are correct and do not demonstrate any change in a treatment-effect estimate.

  • Bounded impact: A 4-day levodopa and 5-day placebo difference in reported medians, with different IQRs.

  • Human verification instruction:

    1. Compare the variable definition, unit, population, and time origin in the main-table and supplement-table production specifications.
    2. Recalculate arm-specific median and IQR values from the locked analysis dataset.
    3. Matching recalculated values to one table confirms which report should be aligned; a difference in variable definition resolves the issue only if that distinction is explicitly added to the reports.

C04 — PRAI placebo numerator differs by one participant

  • Evidence status: Verified; retained by critic.
  • Category / severity: Cross-document inconsistency / Minor.
  • Issue statement: The main article reports 52 of 270 placebo participants with no improvement or no relevant improvement, whereas eTable 4 reports 51 of 270.
  • Exact source locations: jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 6 (journal p. 1528), Secondary Outcomes, patient-reported assessment of relevance of motor improvement sentence. Comparator: joi250066supp3_prod_1761597796.4701.pdf, PDF p. 15, eTable 4, row “PRAI; no (relevant) improvement, 3 months, N. (%),” Placebo and Levodopa columns.
  • Source evidence: Main article: levodopa 51/276 (18%); placebo 52/270 (19%). Supplement: placebo 51 (18.89) with n=270; levodopa 51 (18.48) with n=276; total N 546.
  • Reported-versus-comparator comparison: Placebo numerator 52 versus 51, denominator 270 versus 270. Levodopa numerator and denominator agree.

Reasoning procedure

  1. Reproduce the main-article placebo rate: (52 ÷ 270) × 100 = 19.259...%, which rounds to 19% at whole-percent precision.
  2. Reproduce the supplement placebo rate: (51 ÷ 270) × 100 = 18.888...%, which rounds to 18.89% at two-decimal precision.
  3. Calculate the numerator difference: 52 − 51 = 1 participant.
  4. Calculate the unrounded rate difference: (52 − 51) ÷ 270 × 100 = 0.37037... percentage points.
  5. Whole-percent rounding makes both rates display as 19%; it does not reconcile the exact numerators. Denominators agree and 270 + 276 = 546, matching the supplement total N.

  • Existing supported conclusion: Each document's percentage is internally compatible with its own numerator, but the placebo numerators conflict by one participant.

  • Limit on interpretation: The package does not establish whether 51 or 52 is the validated count and does not show an error in the levodopa result.

  • Bounded impact: One placebo participant and approximately 0.37 percentage points in the unrounded placebo rate.

  • Human verification instruction:

    1. Check the final PRAI derivation for the 270 placebo respondents, including the coding of “no” and “no relevant improvement.”
    2. A source count of 51 confirms eTable 4; 52 confirms the main text. Align the other source and its percentage.
    3. Confirm the levodopa 51/276 and combined denominator 546 remain unchanged unless the source data establish otherwise.

C06 — Estimand 11's written conjunction cannot produce its reported N

  • Evidence status: Verified; retained by critic.
  • Category / severity: Statistical reporting inconsistency / Minor.
  • Issue statement: eTable 3 says Estimand 11 excludes participants meeting both low-rehabilitation and low-medication conditions, but excluding only that intersection cannot yield the reported N=395.
  • Exact source locations: joi250066supp3_prod_1761597796.4701.pdf, PDF p. 14, eTable 3, Estimand 11, Intercurrent Events and Number of participants columns; joi250066supp3_prod_1761597796.4701.pdf, PDF p. 13, eTable 2, Estimands 1, 6, and 7, Number of participants column. Comparator: jama_engelter_2025_oi_250066_1761597796.45511.pdf, PDF p. 4 (journal p. 1526), Statistical Analyses, post hoc estimand sentence.
  • Source evidence: Estimand 11 excludes participants who had low rehabilitation “and” took less than 80% medication, reporting N=395. From the base Full analysis set N=582, Estimand 6 excludes low medication and reports N=496; Estimand 7 excludes low rehabilitation and reports N=450. The main article describes including only participants who received at least 80% medication “and” attended at least 5 rehabilitation sessions per week.
  • Reported-versus-comparator comparison: The literal supplement conjunction describes excluding the intersection of two failure sets. Its reported N instead removes 187 participants, more than the entire smaller failure set of 86; therefore that literal rule cannot produce 395.

Reasoning procedure

  1. Let base population B=582. Let M be participants failing medication adherence and R those failing rehabilitation adherence.
  2. From Estimand 6, |M| = 582 − 496 = 86 participants. From Estimand 7, |R| = 582 − 450 = 132 participants.
  3. Under the literal “exclude M and R” intersection rule, |M ∩ R| ≤ min(86,132) = 86; retained N must therefore satisfy 582 − |M ∩ R| ≥ 582 − 86 = 496.
  4. The printed retained N is 395, which is 496 − 395 = 101 below that mathematical lower bound. Integer rounding tolerance is 0 participants.
  5. The printed 395 excludes 582 − 395 = 187 participants. As a diagnostic explanation, excluding the union gives |M ∩ R| = |M| + |R| − |M ∪ R| = 86 + 132 − 187 = 31, a feasible count.
  6. The main article's positive inclusion rule—meet medication criterion and rehabilitation criterion—is logically equivalent to excluding M ∪ R, not excluding M ∩ R. This explains why the critic found the intended population substantially visible; it does not independently correct the supplement wording.

  • Existing supported conclusion: The literal conjunction in eTable 3 cannot generate N=395; the main-text inclusion rule and displayed N support the apparent intended union-of-failures exclusion.

  • Limit on interpretation: The 31 overlap is a diagnostic consequence if the displayed counts share the same base and definitions. Only analysis code or participant-level flags can establish the implemented rule. The effect estimate 0.32 [−3.25, 3.89] is not shown to be numerically wrong.

  • Bounded impact: A nonreproducible written population rule; the reported N is 101 below the minimum allowed by the literal rule.

  • Human verification instruction:

    1. Inspect the Estimand 11 analysis code and table shell for the Boolean inclusion/exclusion expression.
    2. Confirm counts for medication failure, rehabilitation failure, their overlap, and their union in the same N=582 base.
    3. An overlap of 31 and union of 187, leaving 395, confirms the apparent both-requirements inclusion rule; otherwise document the implemented counts and revise the prose or N accordingly.
