# Independent source check: tobacco-use form in the adjusted abstinence analysis

Date: 2026-10-21. Scope: a bounded source re-exploration of the supplied plan and report passages concerning tobacco-use form as an adjustment covariate. No existing candidate, checker, screening, recheck, audit, or final-report record was read. This document does not compare its conclusions with a prior candidate description or assign a disposition.

## Independent conclusion

The supplied SAP explicitly specifies adjustment for **tobacco use form** in its fully adjusted models. The relevant text is in SAP section **36, Adjusted Analyses**, immediately after section **35, Sensitivity Analyses**, on PDF page 92, printed SAP page 15. Section 30, **Primary outcome Analysis**, on PDF page 91, printed SAP page 14, separately specifies the main primary-outcome model without naming tobacco-use form or other adjustment covariates. Consequently, the supported wording is **a plan-specified adjusted/sensitivity analysis of the primary abstinence outcome**, rather than an established requirement that tobacco-use form enter the main primary model.

The main report supplies a clear adjusted counterpart: the month-6 primary-outcome adjusted risk ratio, 3.2 (95% CI, 2.2–5.2), in the results and Table 2. The report repeatedly describes adjustment for age, sex, education, occupation, and smoking duration, with selection described as post hoc. Tobacco-use form is absent from those printed adjustment lists. The results supplement repeats the same five covariates for its analysis excluding deaths. No separate result explicitly identified as a tobacco-form-adjusted analysis was located in these report materials.

The directly observable discrepancy is therefore between the SAP's explicit covariate specification and the report's explicit adjustment description. The sources do **not** establish that the tobacco-form-adjusted analysis was never performed, that adding the term would change an estimate, or that the SAP was locked before access to outcome data.

## Protocol versions and disclosed changes

The bundle's [table of contents](../../../joi250093supp1_prod_1768590553.08963.pdf#page=1) identifies a study protocol v4.0, a study protocol v6.0, a change statement, and the SAP. The first protocol cover, [PDF p2](../../../joi250093supp1_prod_1768590553.08963.pdf#page=2), labels itself “Study protocol v4.0– earlier version” and gives “V4.0 19th April 2023.”

The first protocol block's statistical-analysis passage, [PDF p28](../../../joi250093supp1_prod_1768590553.08963.pdf#page=28), printed p28, §11.2.2, lines 759–764, says: “Outcomes will be primarily analysed in a missing-at-random architecture by fitting generalised linear mixed models using a log link and assuming an underlying Poisson distribution with clusters treated as a random effect.” It further says: “The crude and adjusted relative risks (RRs) and corresponding 95% CIs will be estimated.” The second protocol block's corresponding passage, [PDF p66](../../../joi250093supp1_prod_1768590553.08963.pdf#page=66), printed p25, §28.2.2, lines 2011–2016, repeats this wording. Neither passage provides the adjustment-covariate list or states an alternative that removes tobacco-use form. These passages were inspected only for the present covariate question; their distribution/link wording is outside this bounded re-exploration.

The complete one-page [“Changes between version v4 and v6” statement](../../../joi250093supp1_prod_1768590553.08963.pdf#page=77), printed p1, lines 2403–2442, describes changes to ethics references, treatment-failure definition, sample sizes, travel allowance, a technology-acceptance substudy, an educational leaflet, and weekly participant calls. It does not describe a tobacco-form covariate change, a replacement adjustment list, or a change to the adjusted/sensitivity analysis under discussion. This is an observation about that supplied change statement, not proof that no other amendment exists.

The [SAP introduction](../../../joi250093supp1_prod_1768590553.08963.pdf#page=78), printed SAP p1, §1, lines 2452–2454, states: “The trial protocol document version 6.0 dated 20.Mar.2025 contains complete details along with the published protocol paper by Zahid M et al. 2025”. No SAP approval, signature, contemporaneous lock date, or data-access history was established in this bounded inspection. Its future-tense analysis specification supports calling it **plan-specified**, but not an independently demonstrated pre-data specification.
