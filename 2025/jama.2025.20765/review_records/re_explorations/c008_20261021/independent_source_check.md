## Independent interpretation under the scope

**Direct fact:** the <6 ppm rows are placed under the primary-outcome block in both report tables. The supplement uses the plural heading “Primary outcomes.” **Direct fact:** the main report preserves the planned <10 ppm primary definition and explicitly describes the <6 ppm analysis as post hoc sensitivity analysis. The main results distinguish the post hoc result from the primary analysis. The supplement's immediately preceding table title identifies the entire display as post-hoc sensitivity analysis after excluding deaths.

**Inference:** the blocks group analyses relating to the primary abstinence outcome, including alternative thresholds and analysis sets. The singular Table 2 block also contains self-report-only and PP rows, supporting this grouping interpretation. A block heading alone does not establish that each row was designated a separate prespecified primary endpoint; the explicit definitions and post hoc descriptions identify the intended roles here. The supplement's plural heading is less precise than the main report's singular heading, but its own caption identifies the analyses as post hoc.

**Comparison tier:** an actual change of primary-outcome status would qualify for consideration as a plan–report comparison. Here the reproduced observation is table grouping, not a demonstrated hierarchy change. A heading-only comparison remains peripheral unless it changes the primary result or planned decision rule; neither is established by these sources.

**Route A, category 5:** no change of the planned primary-outcome status is established. The <10 ppm result is reported as primary, while <6 ppm is explicitly post hoc sensitivity analysis. The proposed contradiction therefore is **NOT_REPRODUCED**; this does not remove an established route A finding through a context exception, because the status change itself has not been reproduced.

**Route B:** no unresolved discrepancy in a named value or result is established. The primary result to extract remains the explicitly defined <10 ppm ITT result, 300/720 versus 55/360; the <6 ppm estimates remain separately labeled threshold analyses. The methods, result narrative, and eTable 9 caption resolve the distinction without assuming any unreported analysis. B2 and B3 are therefore not satisfied for the proposed status-change interpretation. If the observation were framed only as the plural heading's wording, its immediate post-hoc caption would resolve it; that wording alone would not establish a change in endpoint hierarchy.
