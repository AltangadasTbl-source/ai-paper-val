# Limitations and Missing Definitions

- DOC-002 has a glyph-mapped native text layer that is not semantically readable. All 136 pages were freshly mapped from the direct PDF with rendered-page inspection for quantitative and statistical content; native/layout extraction was retained only as a locator. The final SAP pages 126-136 were mapped at section-level visual granularity, and exact candidate evidence on PDF p. 118 was separately rechecked visually.
- DOC-003 graph-only curves, plotted marks, and bin heights that do not print exact numeric values were not digitized or treated as exact numbers. All printed axes, denominators, captions, table values, and labels were mapped.
- For some Table 2 secondary outcomes, the supplied source does not state the exact effect scale/test to which a displayed P value applies or provide the variance/covariance details needed for an exact reconstruction. The statistical reviewers therefore checked direction, interval containment, labels, and supplied-source compatibility without manufacturing a P-value inconsistency.
- Candidate C001 requires human confirmation of the intended placement of `mm Hg`; C002 requires the intended contents-page titles or production history; C003 requires the missing internal-reference target and its intended content.
- Reusable OCR, normalized text, rendered pages, and document maps were used as locators and transcription aids only. Direct supplied PDFs remained authoritative for candidate evidence.
- Authoritative response-level runtime token counts are not exposed in this execution environment. Token accounting will therefore use `UNAVAILABLE` records rather than estimates.
