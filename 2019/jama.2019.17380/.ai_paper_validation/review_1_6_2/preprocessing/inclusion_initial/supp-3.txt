       During the course of measurement, a one-time shift in serum cystatin C measurements

was observed using “high” and “low” serum standards as well as the serum QC set. This shift

corresponded with a change in reagent lot number and calibrators for cystatin C and can be

seen in the Supplementary Methods Figure as a systematic increase in each sample in the QC

set comparing the last three days on which the QC set was run to the first five days on which

the QC set was run (upper and lower left panels).


       Cystatin C standard ERM-DA471/IFCC was run 8 times after the shift was observed. The

observed mean concentration (5.96 mg/L) was slightly higher than the expected concentration

(5.49 mg/L).


       We transformed our cystatin C concentrations to calibrate them with ERM-DA471/IFCC

and harmonize them across the study. First, we calibrated post-shift cystatin C concentrations

(including study samples and QC set samples) by multiplying each value by the ratio of the

expected (5.49 mg/L) to the observed (5.961 mg/L) reference mean. After calibration, we

calculated the mean cystatin C concentration for each of the 20 samples in the QC set
