## Findings

### F-XS-001

The same collapsed-composite result is labeled as a risk ratio in the main report and an odds ratio in the results supplement.

- **Exact locations and document roles:** REPORT [main abstract, PDF p.1](../../../jama_bluth_2019_oi_190055_16092.pdf#page=1), REPORT [primary analysis methods, p.4](../../../jama_bluth_2019_oi_190055_16092.pdf#page=4), REPORT [Table 3 primary PPC row, p.9](../../../jama_bluth_2019_oi_190055_16092.pdf#page=9), REPORT [Figure 2 all-patients row and Table 3 footnote b, p.10](../../../jama_bluth_2019_oi_190055_16092.pdf#page=10), and REPORT [results supplement eFigure 12, Global Tests/Collapsed Composite, p.42](../../../joi190055supp4_prod_16092.pdf#page=42).
- **Printed values:** Main report identifies 0.93 (95% CI 0.83–1.04) as a risk ratio for the five-day composite, 211/989 versus 233/987. eFigure 12 prints the identical 0.93 [0.83, 1.04] in the Collapsed Composite row under “Odds Ratio (95% CI)”. The other global rows are explicitly odds-based models, making this shared header meaningful. The [final SAP primary method, PLAN p.2](../../../joi190055supp3_prod_16092.pdf#page=2) specifies risk ratios; it corroborates the main label and is not an additional conflicting relationship.
- **Comparison logic:** Match the primary collapsed composite, randomized high-versus-low contrast, five-day time window, all-patient population and 95% interval. The complete estimate/interval triple is repeated under two different quantity labels. RR and OR identify different statistical quantities; matching displayed precision cannot reconcile their labels. No crude recomputation is used to infer which quantity was calculated, and no model-based value is equated with a crude ratio.
- **Focus area:** B and C.
- **Proposed review domain:** statistical_results.
- **Proposed relationship:** S_C. All conflicting relationships: S_C. The protocol/SAP only corroborates one side.
- **Affected result or extracted value:** The primary five-day PPC effect 0.93 (0.83–1.04), which a data extractor could encode as either RR or OR.
- **Why context does not resolve it:** eFigure 12 deliberately distinguishes component risk ratios from global odds ratios; its local Collapsed Composite row has no exception to the odds-ratio header. The main methods and table explicitly identify a risk ratio, while the supplementary figure could be presenting a separately modeled odds ratio. The complete repeated triple suggests a matched result but does not establish which label or analysis applies. Immediate figure context therefore cannot settle the measure identity.
- **Supported alternatives:** The collapsed-composite row could repeat the main RR under the global header, or it could represent a separate odds-based analysis with the same displayed estimate/interval. The supplied report does not describe such a separate collapsed-composite odds model. Both alternatives require human confirmation; neither is selected here.
- **Human verification steps:** Inspect eFigure 12's two headers and the collapsed-composite row, then compare the main abstract, primary methods, Table 3 and Figure 2. Identify the analysis and link function that generated the collapsed-composite row. Confirm whether that row is the main incidence analysis or a distinct model and which effect measure should accompany 0.93 (0.83–1.04).

### F-XS-002

The protocol and report use different oxygen-response criteria to distinguish mild and moderate respiratory failure within the primary composite.

- **Exact locations and document roles:** PLAN [protocol version 2.6 Appendix iii, PDF p.31](../../../joi190055supp1_prod_16092.pdf#page=31), REPORT [results supplement eMethods 2.8, p.20](../../../joi190055supp4_prod_16092.pdf#page=20), REPORT [Table 3 respiratory failure rows, p.9](../../../jama_bluth_2019_oi_190055_16092.pdf#page=9), and REPORT [Table 3 footnote d, p.10](../../../jama_bluth_2019_oi_190055_16092.pdf#page=10). PLAN [final SAP outcome list, p.1](../../../joi190055supp3_prod_16092.pdf#page=1) retains mild/moderate/severe components and refers to their definitions elsewhere; it supplies no replacement oxygen criterion. The supplied [amendment list, pp.1–3](../../../joi190055supp2_prod_16092.pdf#page=1) records no respiratory-severity amendment.
- **Printed statements and associated values:** Protocol mild respiratory failure is PaO2 <60 mmHg or SpO2 <90% in room air for at least 10 minutes “but responding to supplemental oxygen”, without a flow threshold. Protocol moderate respiratory failure is PaO2 <60 mmHg or SpO2 <90% “despite supplemental oxygen”. Main Table 3 footnote d instead classifies response to ≤2 L oxygen as mild and response only to >2 L as moderate, following the room-air criterion. eMethods likewise defines moderate as a room-air abnormality responding only to >2 L/min oxygen. The printed eMethods mild “= 2 L/min” is read with the unequivocal main ≤2 criterion and is not a separate finding. Table 3 mild counts are 135/989 and154/987; moderate42/989 and58/987; severe-composite116/989 and134/987. Mild failure is excluded from the severe composite, as [REPORT eMethods p.21](../../../joi190055supp4_prod_16092.pdf#page=21) and [PLAN final SAP p.1](../../../joi190055supp3_prod_16092.pdf#page=1) state.
- **Comparison logic:** Match the first-five-day primary pulmonary-complication components, eligible analyzed surgical population and oxygen-response classification. “Responding only to >2 L” and “despite supplemental oxygen” are not the same operational criterion: one classifies by flow needed to resolve room-air hypoxemia, the other by hypoxemia persisting on oxygen. The plan also does not limit mild failure to≤2 L. This is a threshold/definition comparison, without assuming any patient's actual reclassification or computing an alternative event count.
- **Focus area:** D.
- **Proposed review domain:** protocol_report.
- **Proposed relationship:** P_R. All conflicting relationships: P_R. The two REPORT definitions corroborate one another after the locally resolvable mild-flow glyph is screened separately.
- **Affected result or extracted value:** Definition accompanying the primary-composite respiratory-component counts (mild135/154, moderate42/58) and the severe pulmonary composite116/134, which excludes mild respiratory failure. The overall composite incidence211/233 is not asserted to change; mild and moderate both belong to it.
- **Why context does not resolve it:** The different oxygen-response thresholds determine which severity category a qualifying event belongs to and thus can determine membership in the severe composite. A reader can understand both definitions but cannot identify from immediate context which operational rule governed data collection/classification or whether a further endpoint amendment occurred. Final SAP and disclosed amendments do not state a replacement respiratory-severity rule.
- **Supported alternatives:** The report could describe a later operational refinement that classified events by required oxygen flow, or the protocol criterion could have governed collection while the report summarizes severity differently. The supplied evidence does not establish which occurred or its numerical consequences.
- **Human verification steps:** Compare protocol Appendix iii with Table 3 footnote d and eMethods 2.8. Check the study case-report-form/data-dictionary respiratory-severity criteria and any approved definition amendment available to human reviewers. Establish whether hypoxemia persisting despite oxygen or oxygen flow needed for response classified moderate events, and confirm which definition accompanies the printed component/severe-composite counts.
